ALAS2PHP8.2-2026-013
Amazon Linux 2 (EOS) Security Advisory: ALAS2PHP8.2-2026-013
Advisory Released Date: 2026-08-04
Advisory Updated Date: 2026-08-04
Severity:  Critical
References: CVE-2026-17543  CVE-2026-7260  CVE-2026-9672
FAQs regarding Amazon Linux ALAS/CVE Severity
Issue Overview:
Improper escaping of backslashes in attacker-provided parameters would allow for trivial SQL injection in PHP versions from 8.2.* before 8.2.33, from 8.3.* before 8.3.33, from 8.4.* before 8.4.24, and from 8.5.* before 8.5.9. (CVE-2026-17543)

Circular symbolic links in phar archives could lead to unbounded recursion, exhausting the C stack and crashing the PHP process, in PHP versions from 8.2.* before 8.2.33, from 8.3.* before 8.3.33, from 8.4.* before 8.4.24, and from 8.5.* before 8.5.9. (CVE-2026-7260)

NOTE: Fixed by: https://github.com/php/php-src/commit/b590f0380fda26ed180874a0255f0be078434315 (php-8.4.24)
DEBIANBUG: [1143152] (CVE-2026-9672)
